🎓 Student Placement Management System

### **A Data Structures and Algorithms (DSA) Project using Python**

🌟 About the Project

The **Student Placement Management System** is a Python-based application designed to simplify and organize the college placement process.

It helps manage student records, company requirements, placement eligibility, and job applications using fundamental Data Structures and Algorithms (DSA).

The system checks whether students meet company-specific CGPA and branch requirements before allowing them to apply for placement opportunities.

🎯 Project Objectives

- Manage student records efficiently.
- Maintain company placement requirements.
- Automate placement eligibility checking.
- Organize placement applications in FIFO order.
- Demonstrate the practical use of DSA concepts.

✨ Key Features

| Feature                     | Description                               |
| --------------------------- | ----------------------------------------- |
| 👨‍🎓 Student Management    | Add and display student records           |
| 🔍 Student Search           | Find students using their unique ID       |
| 📊 CGPA Sorting             | Sort students by CGPA in descending order |
| 🏢 Company Management       | Add, display, and search companies        |
| ✅ Eligibility Checking      | Verify CGPA and branch requirements       |
| 🎯 Eligible Student Listing | Display students eligible for a company   |
| 📝 Application System       | Submit valid placement applications       |
| 🔄 Queue Processing         | Process applications in FIFO order        |

🧠 Data Structures & Algorithms
1. List

Stores student records, company records, and placement applications.

2. Hash Table

Python dictionaries store students and companies using their unique IDs, enabling efficient average-case lookup.

3. Sorting

Students are sorted by CGPA in descending order using Python's built-in sorting functionality.

4. Queue

Placement applications are processed using the **FIFO (First In, First Out)** principle.

⚙️ Technologies Used

- **Programming Language:** Python 3
- **Concepts:** Object-Oriented Programming (OOP) and DSA
- **Data Structures:** Lists, Dictionaries, and Queue
- **Development Environment:** Any Python-compatible editor or terminal

🚀 Getting Started

Prerequisites

Install Python 3 on your computer.

Installation & Execution

**Step 1:** Clone or download this repository.

**Step 2:** Open the project folder in Command Prompt or a terminal.

**Step 3:** Run the program using:

```bash
python placement_system.py
```

**Step 4:** Use the interactive menu to manage students, companies, eligibility checks, and applications.

🧪 Example Use Case

A company requires:

- Minimum CGPA: 7.0
- Required Branch: CSE

A student with a CGPA of 8.5 from CSE meets both requirements and is marked **ELIGIBLE**.

A student who fails either requirement is marked **NOT ELIGIBLE**, with the reason displayed.
